## 8. Precision review (MODEL-CODED, pending user confirmation)

Coder: **model-coded (Claude, 2026-09-29), pending user confirmation**. Each sampled description was read in full and coded for what it actually states: `enclave` (the property is inside a gated / access-controlled estate or complex), `guard_service` (guards, armed response or a named PSC serve the property), `hardening` (electric fence, access-control technology, security walls on the property or building), `commercial` (non-residential use). `not PSC` = none of the first three. The user should confirm or overturn these codes by editing `scripts/scraping/tests/fixtures/precision_labels_2026-09-29.csv` and re-running this script. Uncoded sampled rows: 0.

Caveats: (i) coding was **not blind**, since the coder saw the flag values and wrote the patterns, so the estimates below are upper bounds; (ii) keyword precision is high by construction ('24 hour security' does state a guard). The substantive question is **which construct** a flag measures: compare the enclave and commercial rows; (iii) 'secure complex' / 'security complex' were coded as enclaves on the conventional South African meaning (a unit complex with a controlled gate), and the user should confirm; (iv) n = 20-25 per sample, so the intervals are wide.
